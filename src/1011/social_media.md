## 💼 LinkedIn Post (Plain Text Only - No Markdown)

How do you optimize for the "minimum" of something when the solution space is sorted?

That is the core challenge of LeetCode 1011 (Capacity To Ship Packages Within D Days).

🔹 The Goal
Find the minimum ship capacity to deliver all packages in a set number of days.

🔹 The Solution
We use a "Binary Search on Answer" approach to solve this in O(N log S) time.

• Step 1: Define the range (Max weight to Sum of weights).
• Step 2: Use a greedy simulation to check if a capacity is feasible.

This technique is incredibly powerful for optimization problems where the feasibility function is monotonic.
