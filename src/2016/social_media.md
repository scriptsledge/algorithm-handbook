## 💼 LinkedIn Post (Plain Text Only - No Markdown)

How do you optimize a search for pairs in an array?

The naive approach is O(N^2), but when sequence matters, we can often do better.

That is the core challenge of LeetCode 2016 (Maximum Difference Between Increasing Elements).

🔹 The Goal
Find the largest gap between nums[i] and nums[j] where i < j.

🔹 The Solution
We use a "Min So Far" approach to solve this in O(N) time.

• Step 1: Track the minimum value encountered as you iterate.
• Step 2: For every new element, calculate the difference with that minimum.

This greedy strategy ensures we find the global maximum without redundant comparisons.
