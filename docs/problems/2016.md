## 📝 Problem Description

!!! info "Problem Statement"
    Given a **0-indexed** integer array `nums` of size `n`, find the **maximum difference** between `nums[i]` and `nums[j]` (i.e., `nums[j] - nums[i]`), such that `0 <= i < j < n` and `nums[i] < nums[j]`.

    Return *the **maximum difference***. If no such `i` and `j` exists, return `-1`.

### Examples

**Example 1:**
- **Input:** `nums = [7,1,5,4]`
- **Output:** `4`
- **Explanation:** The maximum difference occurs with `i = 1` and `j = 2`, `nums[j] - nums[i] = 5 - 1 = 4`. Note that with `i = 1` and `j = 0`, the difference `nums[j] - nums[i] = 7 - 1 = 6`, but `i > j`, so it is not valid.

**Example 2:**
- **Input:** `nums = [9,4,3,2]`
- **Output:** `-1`
- **Explanation:** There is no `i` and `j` such that `i < j` and `nums[i] < nums[j]`.

**Example 3:**
- **Input:** `nums = [1,5,2,10]`
- **Output:** `9`
- **Explanation:** The maximum difference occurs with `i = 0` and `j = 3`, `nums[j] - nums[i] = 10 - 1 = 9`.

### Constraints

- `n == nums.length`
- `2 <= n <= 1000`
- `1 <= nums[i] <= 10^9`

## 🧠 Intuition

The problem requires finding two indices $i$ and $j$ such that $i < j$ and $nums[i] < nums[j]$, and maximizing the difference $nums[j] - nums[i]$. This is essentially finding the best profit in a stock-like problem where you must buy before you sell. To maximize the difference, we want to subtract the smallest possible value we've encountered so far from the current element.

## 💡 Approach

1.  **Initialize**: Set `minSoFar` to the first element and `maxDiff` to `-1`.
2.  **Iterate**: Loop through the array starting from index 1.
3.  **Calculate Difference**: If the current element `nums[i]` is greater than `minSoFar`, it means we've found a valid pair. Calculate the difference and update `maxDiff` if this difference is larger than our current `maxDiff`.
4.  **Update Minimum**: If the current element is smaller than `minSoFar`, update `minSoFar`. This allows future elements to potentially find an even larger difference.
5.  **Return**: After the loop, `maxDiff` will hold the maximum difference found, or `-1` if no valid pair exists.

## 📊 Complexity Analysis

*   **Time Complexity:** $O(N)$
    We traverse the array exactly once, performing constant time operations at each step.

*   **Space Complexity:** $O(1)$
    We only use two integer variables (`minSoFar` and `maxDiff`) regardless of the input size.
