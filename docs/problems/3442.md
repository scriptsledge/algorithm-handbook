## 📝 Problem Description

!!! info "Problem Statement"
    You are given a string `s` consisting of lowercase English letters.

    Your task is to find the maximum difference `diff = freq(a1) - freq(a2)` between the frequency of characters `a1` and `a2` in the string such that:
    - `a1` has an **odd** frequency in the string.
    - `a2` has an **even** frequency in the string.

    Return this maximum difference.

### Examples

**Example 1:**
```text
Input: s = "aaaaabbc"
Output: 3
Explanation:
The character 'a' has an odd frequency of 5, and 'b' has an even frequency of 2.
The maximum difference is 5 - 2 = 3.
```

**Example 2:**
```text
Input: s = "abcabcab"
Output: 1
Explanation:
The character 'a' has an odd frequency of 3, and 'c' has an even frequency of 2.
The maximum difference is 3 - 2 = 1.
```

### Constraints
- `3 <= s.length <= 100`
- `s` consists only of lowercase English letters.
- `s` contains at least one character with an odd frequency and one with an even frequency.

## 🧠 Intuition

To maximize the difference $freq(a_1) - freq(a_2)$, we need to make $freq(a_1)$ as large as possible and $freq(a_2)$ as small as possible. Since $a_1$ must have an odd frequency and $a_2$ must have an even frequency, we simply need to find the maximum odd frequency and the minimum non-zero even frequency present in the string.

## 💡 Approach

1.  **Count Frequencies:** Use an array of size 26 to store the frequency of each character 'a' through 'z'.
2.  **Identify Extremes:**
    -   Iterate through the frequency array.
    -   If a frequency is odd, update our `max_odd` variable.
    -   If a frequency is even (and greater than zero), update our `min_even` variable.
3.  **Calculate Result:** Return `max_odd - min_even`.

*   **Time Complexity:** $O(N)$

    The frequency array is of size 26, which is constant space regardless of the input string length.
