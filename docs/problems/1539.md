## 📝 Problem Description

!!! info "Problem Statement"
    Given an array `arr` of positive integers sorted in a strictly increasing order, and an integer `k`.
    Return the *kth* positive integer that is missing from this array.

### Examples

**Example 1:**
- **Input:** `arr = [2,3,4,7,11], k = 5`
- **Output:** `9`
- **Explanation:** The missing positive integers are `[1,5,6,8,9,10,12,13,...]`. The 5th missing positive integer is 9.

**Example 2:**
- **Input:** `arr = [1,2,3,4], k = 2`
- **Output:** `6`
- **Explanation:** The missing positive integers are `[5,6,7,...]`. The 2nd missing positive integer is 6.

### Constraints

- `1 <= arr.length <= 1000`
- `1 <= arr[i] <= 1000`
- `1 <= k <= 1000`
- `arr[i] < arr[j]` for `1 <= i < j <= arr.length`

## 🧠 Intuition

In a perfectly sequential array starting from 1 with no missing numbers, the value at index `i` would be `i + 1`. For example, at index 0, the value would be 1; at index 4, the value would be 5.

If numbers are missing, the value `arr[i]` will be greater than `i + 1`. The difference `arr[i] - (i + 1)` tells us exactly how many numbers are missing up to that point.

## 💡 Approach

Since the array is sorted, we can use **Binary Search** to find the region where the $k^{th}$ missing number is located.

1.  **Search Range:** Initialize `left = 0` and `right = arr.size() - 1`.
2.  **Missing Count:** At each step, calculate the middle index `mid` and the count of missing numbers before `arr[mid]`:
    `missing = arr[mid] - (mid + 1)`
3.  **Adjust Bounds:**
    *   If `missing < k`, the $k^{th}$ missing number must be further to the right. Set `left = mid + 1`.
    *   If `missing >= k`, the $k^{th}$ missing number is either at `mid` or to the left. Set `right = mid - 1`.
4.  **Result Calculation:** When the loop ends, `left` is the smallest index where the number of missing integers is at least `k`.
    The answer is `left + k`.
